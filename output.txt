==========================================================================================
C1. Shuffle - operation nào gây Exchange?
==========================================================================================
Shuffle = Spark phải chuyển dữ liệu giữa các executor qua mạng/đĩa để gom các dòng
cùng key về cùng partition. Đây thường là bước ĐẮT NHẤT của job.
  - Narrow (KHÔNG shuffle): select, filter, withColumn, cast, union...
  - Wide   (CÓ shuffle)   : join, groupBy/agg, distinct, orderBy, repartition...
   filter + withColumn (narrow)     -> số Exchange (shuffle): 0
   groupBy + sum (wide)             -> số Exchange (shuffle): 1
   join với customers (wide)        -> số Exchange (shuffle): 2

>> Plan của groupBy (tìm dòng 'Exchange hashpartitioning'):
== Physical Plan ==
*(2) HashAggregate(keys=[customer_id#4753], functions=[sum(amount#4754)])
+- Exchange hashpartitioning(customer_id#4753, 8), ENSURE_REQUIREMENTS, [plan_id=539]
   +- *(1) HashAggregate(keys=[customer_id#4753], functions=[partial_sum(amount#4754)])
      +- *(1) Project [CASE WHEN ((id#4752L % 10) < 8) THEN 101 ELSE cast(((id#4752L % 4) + 102) as int) END AS customer_id#4753, cast((rand(42) * 1000000.0) as decimal(12,2)) AS amount#4754]
         +- *(1) Range (0, 400000, step=1, splits=8)


Ghi nhớ: groupBy sinh 2 bước HashAggregate (partial -> shuffle -> final).
Partial aggregate chạy TRƯỚC shuffle nên dữ liệu gửi đi đã được thu nhỏ: đó là lý do
agg(sum/count) rẻ hơn nhiều so với groupBy rồi mới xử lý từng nhóm.

C2. repartition vs coalesce
==========================================================================================
>> df_big hiện có 8 partition
   repartition(8)                 -> 8 partition, shuffle: 1
   repartition(4, 'customer_id')  -> 4 partition, shuffle: 1
   repartition(8).coalesce(2)     -> 2 partition

>> Plan coalesce trực tiếp trên df_big (chú ý: KHÔNG có Exchange mới cho coalesce):
== Physical Plan ==
Coalesce 2
+- *(1) Project [id#4752L AS order_id#4755L, customer_id#4753, amount#4754]
   +- *(1) Project [id#4752L, CASE WHEN ((id#4752L % 10) < 8) THEN 101 ELSE cast(((id#4752L % 4) + 102) as int) END AS customer_id#4753, cast((rand(42) * 1000000.0) as decimal(12,2)) AS amount#4754]
      +- *(1) Range (0, 400000, step=1, splits=8)


So sánh:
  repartition(n) : FULL SHUFFLE, chia đều được, TĂNG hoặc GIẢM số partition.
                   Dùng khi: cần tăng song song, sửa partition lệch, hoặc chia theo cột
                   (repartition(n, 'col')) trước join/groupBy/ghi file partitionBy.
  coalesce(n)    : KHÔNG shuffle, chỉ gộp partition cạnh nhau -> chỉ GIẢM được,
                   partition có thể không đều. Dùng khi: giảm số file nhỏ trước khi ghi.
  Lưu ý: export_single_csv() ở dưới dùng coalesce(1) -> toàn bộ dữ liệu ghi bởi 1 task.
         OK với bài nhỏ này, nhưng với dữ liệu lớn sẽ là nút thắt (chậm/OOM).
